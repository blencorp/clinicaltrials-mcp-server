## ChatGPT and other remote clients

ChatGPT, Claude custom connectors, and Gemini Enterprise connect to a remote server over HTTPS. They
do not start a server on your computer.

BLEN hosts one at `https://clinicaltrials.mcp.blencorp.com/mcp`. Add that URL as a custom
connector. There is no sign-in and no key. The hosted server offers `search_api` and
`describe_schema`, so your assistant can look up the SDK and its fields, but it cannot run code. To
run queries, connect a client that starts the server on your computer (above).

To offer `execute` to a remote client, run your own instance: see [Self-host](/self-host/).

## Check that it works

Ask your assistant:

> Summarize the eligibility criteria of study NCT04852770.

The assistant calls `search_api` to find the right methods, then `execute` to run them.

| Message | Cause | Fix |
| --- | --- | --- |
| `ValidationError` | A program passed a parameter that the method does not take. | Read the message: it names the key. See the [SDK reference](/reference/sdk/#search-parameters). |
| `NotFound` | The NCT ID is not in ClinicalTrials.gov. | Check the ID. It is `NCT` and eight digits. |
| `ResultTooLarge` | A program returned more than 256 KiB. | Pass `fields`, and return only what you need. |
| `Busy` | The server is running its limit of programs at once. | Wait, and try again. See [Limits](/keys/#limits). |
| `SandboxUnavailable` | No sandbox runtime is available for `execute`. | Install [Deno](https://docs.deno.com/runtime/getting_started/installation/). |
| `Tool execute not found` | You are connected to the hosted `/mcp`, which has only the documentation tools. | Connect a client that runs the server on your computer. |

<Aside>
  The built-in sandbox needs no install on Node.js 24 and 26 on macOS (Apple silicon), Linux (x64
  and arm64), and Windows (x64). On other systems the server uses Deno.
</Aside>
